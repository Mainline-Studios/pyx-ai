MI Moderator

Hit the check endpoint with the text in the path. Response looks like {"appropriate":false,"score":"700"}. Score is 0–1000; higher means more severe. Default threshold is 700.

GET https://pyx-ai.web.app/moderator/check/<text>

Stricter games: lower the threshold. More permissive: raise it.

Add it to your game

One GET request. Compare appropriate (or your own threshold vs score) before showing chat, names, or custom text.

  1. URL-encode the player text and call /moderator/check/<text>.
  2. Optional: pass ?threshold=700 so the API sets appropriate for you.
  3. If appropriate is false, block, censor, or ask the player to rephrase.
  4. Tune threshold per mode (kids server vs mature lobby).
fetch("https://pyx-ai.web.app/moderator/check/" + encodeURIComponent(text) + "?threshold=700")
  .then((r) => r.json())
  .then((data) => {
    // data → { "appropriate": false, "score": "700" }
    if (!data.appropriate) {
      // block or rewrite the message
    }
  });
