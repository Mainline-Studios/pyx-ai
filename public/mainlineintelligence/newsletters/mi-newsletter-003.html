marii ask now runs on pyx assistant

The public path /api/marii/ask/<request> is no longer an echo box. It loads the same local pipeline as Pyx Assistant: SLU, math, live sports, weather, the notebook, wiki — then an honest miss if the overlap is too thin.

try it from the url

Ask anything after the last slash. Spaces become %20. Example: /api/marii/ask/how%20is%20judge hits the MLB card, not a parrot. Same thing from the try-it box on MI home.

no cloud run, no cloud llm

Hosting serves a tiny page. The browser does the work. If Cloud Run is billed off or 503s, ask still answers. MARII stays local-first.
