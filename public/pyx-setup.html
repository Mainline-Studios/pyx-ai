Requires the Pyx 1.5+ desktop app. Pyx Talk, Code, and Pyxel connect to your local Llama / GPT-OSS models through the Pyx 1.5 desktop launcher. On pyx-ai.web.app, use the download page for macOS / Windows installers (same files as GitHub Releases). Get Pyx 1.5 →

Everything runs on your machine.

Pyx downloads Llama and GPT-OSS weights as .gguf files (no Ollama app required). Put pyx-llama4-scout.gguf (Llama 4 Scout for Pyx 1.5 + Reasoning) and pyx-gpt-oss.gguf (GPT-OSS for Pyx Code + Pyxel 1) in your Pyx models folder, or set download URLs in gguf_manifest.json. Pyx Mini (Llama 2) uses Ollama llama2:7b by default — not the same single-GGUF server path. Install llama.cpp llama-server on your PATH, or set PYX_LLAMA_SERVER to its full path. Optional: PYX_USE_OLLAMA=1 restores the legacy Ollama flow.
