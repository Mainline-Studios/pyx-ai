# Pyx 1.05 — Schoolhouse Patches

**Status:** LATEST · **Date:** 2026-05-17 · **Deploy:** `npm run deploy` (hosting + Cloud Run API)  
**Preceded by:** [1.0 Schoolhouse](1.0%20Schoolhouse.md) · **Superseded by:** —

Schoolhouse Patches tighten the Workspace essay flow so Pyx **coaches** instead of **auto-writing** — hints only, student-owned gaps, and a clearer three-part essay workbench.

## Highlights

### Workspace — “Your essay” three-part flow

- **What Pyx made for you** — topic, thesis idea, outline, research notes, and citations from the plan Pyx built (read-only).
- **Your gaps — you write here** — fill-in sections stay in the student’s text areas; Pyx does not paste answers in.
- **Help from Pyx** — **Review my sources & give hints** looks at saved/read links and progress; responses are nudges and questions, not submit-ready paragraphs.
- Per-gap **Hint from Pyx** buttons call the hint API and show guidance in a hint box below each gap (never in the answer field).
- Workflow step renamed to **4. Your essay** (was “blanks”); **Read my links & build my essay** no longer auto-fills all gaps or jumps to export.

### Backend (Cloud Run `pyxaiapi`)

- **`POST /api/studio/hint`** — hints for one gap (`blank` required); strict “no full answer” coach prompt.
- **`POST /api/studio/help`** — review mode across all sources and gap progress; overview hints only.
- **`POST /api/studio/fill`** — kept for compatibility; now returns `hints` (same hint-only behavior as `/hint`).
- Research coach copy updated for **build my essay** + hints (not auto fill-in).

### Pyx Studio Workspace UI

- Essay workbench in `pyx-workspace.html` + `pyx-studio-workspace.js`: new panels, progress on essay step, removed bulk auto-fill.
- **Open on web** tab: DuckDuckGo and most sites block iframes — placeholder + **Open search in new tab** / result links use `target="_blank"` (no broken embedded search).
- Shared studio **footer** link to trainer sign-in (`/pyx-trainer-auth.html`) via `pyx-shell.js` on Studio shell pages.

### Firebase Hosting

- Rewrites for **`/api/studio/**`** to Cloud Run `pyxaiapi` (unchanged path; required for live `/hint` and `/help`).
