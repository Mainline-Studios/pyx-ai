# Pyx 1.0 — Schoolhouse

**Status:** Archived · **Date:** 2026-05-17  
**Preceded by:** — · **Superseded by:** [1.05 Schoolhouse Patches](1.05%20Schoolhouse%20Patches%20LATEST.md)

Schoolhouse is the first tracked Pyx Studio release aimed at **school and everyday writing** — essay help, web research, and fill-in-the-blanks without coding jargon.

## Highlights

### Pyx Studio (home)

- Studio hub at `/` with continue links, recipes, and quick search into Talk, Code, Pyxel, or Workspace.
- Shared navigation shell across apps (Studio, Workspace, Talk, Code, Pyxel, Speak, Gallery).
- Cross-app **handoffs** so text and plans move between apps without copy-paste.
- **Pyx Gallery** for saving essay packs and favorites.

### Pyx Studio Workspace (essay helper)

- **Start with Pyx** — research coach tells students what to search; embedded web browser opens automatically.
- **Save link** on search results; **Read my saved links** loads article text through Pyx.
- **Read my links & help fill in** — reads pinned URLs, builds an **essay plan**, then helps complete **fill-in-the-blank** sections.
- Kid-friendly copy: “essay plan” and “fill in the blanks” (no JSON/Python in the main UI).
- **Your plan** tab shows a readable outline; technical export is tucked under “For teachers & coding apps (advanced)”.
- Flashcards, study week, task list, and focus timer on the same page.

### Backend (Cloud Run `pyxaiapi`)

- `/api/studio/guide` — step-by-step search plan from Pyx.
- `/api/studio/search` — web search for results + browser URL.
- `/api/studio/read` and `/api/studio/read-sources` — read saved links for research.
- `/api/studio/essay` — structured essay plan with outline and blanks.
- `/api/studio/fill` and `/api/studio/export` — suggestions and merged plan export.

### Firebase Hosting

- Rewrites for `/api/studio/**` (and related API paths) to Cloud Run so the live site returns JSON, not HTML errors.

### Also in this era (Talk & polish)

- Pyx Talk: orbits nav, conversation persistence, vision attachments, Pyx 1.3 preview line.
- Shared **Pyx Cosmos** design across web apps.
- Pyx Speak / Tacotron deploy fixes on Cloud Run.
