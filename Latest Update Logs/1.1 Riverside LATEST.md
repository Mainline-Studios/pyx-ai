# Pyx 1.1 — Riverside

**Status:** LATEST · **Date:** 2026-05-17 · **Deploy:** `npm run deploy` (hosting + Cloud Run API)  
**Preceded by:** [1.05 Schoolhouse Patches](1.05%20Schoolhouse%20Patches.md) · **Superseded by:** —

Riverside is the **flow** release: research moves downstream into your outline, your draft reads like a river, and Pyx checks whether each bend connects — still **hints only**, never a finished essay.

## Highlights

### Workspace — Riverside tab

- **Research river** — horizontal path from saved links (upstream) through arrows to essay sections (downstream); shows read status on each source.
- **Draft stream** — your topic, thesis, outline, and gap answers in one scrollable read-through; **Copy draft stream** for Talk or printing.
- **Flow check** — Pyx comments on how sections connect (metaphors + guiding questions); does not rewrite paragraphs.
- Workflow step **5. Riverside**; hero badge **Riverside · research flows into writing**.
- Cyan/teal river styling on the Workspace.

### Backend (Cloud Run `pyxaiapi`)

- **`POST /api/studio/flow`** — Riverside flow coach using outline, gaps, and read sources; strict no–full-answer rules (same family as `/hint` and `/help`).

### Pyx Studio hub

- New recipe **Riverside essay flow** — topic → Workspace → Riverside tab → Talk.
- Workspace promo copy updated for coach + hints + Riverside.

### Carried forward from Schoolhouse / Patches

- Three-part **Your essay** workbench, `/api/studio/hint`, `/api/studio/help`, trainer footer, DuckDuckGo new-tab search.
