Maestro ships two creative apps at milestone versions: **Pyx Write 0.5** (instrumental composition) and **Pyxel 1.0** (reliable GPT-OSS pixel art), plus Groq GPT-OSS fixes so neither app returns empty LLM content.

## Highlights

### Pyx Write — 1.0 (singing voice), 0.5, 0.25

- **Model dropdown** in Pyx Write:
  - **1.0** — GPT-OSS composes a song with a lead **singing voice that sings real words** plus a backing band. The voice is rendered in-browser by a **phoneme singing synth**: an English grapheme→phoneme converter feeds pitched vowel formants plus consonant noise/plosive/nasal synthesis (vibrato included — it sings, it does not speak; no Pyx Talk involved). The sung lyric line is shown under the result.
  - **0.5** — instrumental, best quality (GPT-OSS).
  - **0.25** — faster/simpler drafts (Llama 3.1 8B).
- New `voice` instrument + per-note `syllable` (ah, ee, oo, la, doo, mm, …); the lead voice is forced monophonic server-side.
- Optional **Vocal feel** field for 1.0; presets; browser playback via Tone.js; export score JSON.
- `POST /api/write/compose` accepts `write_profile` (1.0 / 0.5 / 0.25) and `lyric_theme`.

### Pyxel 1.0

- GPT-OSS pixel generation hardened (`reasoning_format: hidden`, reasoning fallbacks, token retries).
- UI and API report **Pyxel 1.0** / `engine: pyxel-1.0`.

### Shared LLM layer

- `pyx_llm_utils.py` — Groq GPT-OSS content extraction and completion retries used by Write, Pyxel, Talk, and Code paths.
